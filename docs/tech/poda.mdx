# Proof of Data Availability

PoDA lets a publisher put data on Syscoin Core and refer to it by its hash. Core nodes receive the full bytes when validating a fresh publication. A zkSYS Edgechain can publish a batch this way and send only its ordered blob identifiers to Gateway. Anyone with a copy can hash it and compare the result with the commitment. [Data availability architecture](../architecture/data-availability.mdx) · [Core RPC reference](../reference/core.mdx)

Whole-blob validation costs bandwidth in proportion to the payload. Core keeps recent bytes for a limited period. After that, an application that needs to replay a batch relies on an archive for the blobs, the authenticated starting state, and the other execution inputs.
