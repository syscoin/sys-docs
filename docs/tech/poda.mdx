# Proof of Data Availability

PoDA is Syscoin Core’s data publication mechanism. The publication transaction commits to the payload. Nodes handle the payload separately from the transaction and apply their retention rules. Use an archival source when you need historical bytes for replay.

[Data availability architecture](/docs/architecture/data-availability) covers versioned hashes, sidecar validation, retention, archival retrieval, and how zkSYS references published data. [Core RPC reference](/docs/reference/core) shows how to inspect the interface for your release.
