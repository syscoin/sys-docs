Syscoin Core derives its UTXO transaction model, Script interpreter, and wallet tooling from Bitcoin Core. Syscoin uses its own network parameters, block format, and consensus rules. AuxPoW adds Bitcoin-compatible merge-mining, and Syscoin’s separate NEVM chain executes EVM transactions. ## Taproot/Schnorr

Core v5.1.3 enables Taproot on the Syscoin UTXO chain on mainnet and Tanenbaum. Taproot is a SegWit version 1 output type. A key-path spend reveals a BIP340 Schnorr signature for the output key. A Tapscript spend reveals the selected script and control block, which the node checks against the output’s commitment. Unused script branches stay hidden. The amount of witness data and what the spend reveals depend on the path used. [Mainnet parameters](https://github.com/syscoin/syscoin/blob/ff8df9b44d603faf3cf78af28c633a066a8ec9a7/src/kernel/chainparams.cpp#L189-L193) · [Tanenbaum parameters](https://github.com/syscoin/syscoin/blob/ff8df9b44d603faf3cf78af28c633a066a8ec9a7/src/kernel/chainparams.cpp#L354-L358) · [Syscoin script validation](https://github.com/syscoin/syscoin/blob/ff8df9b44d603faf3cf78af28c633a066a8ec9a7/src/script/interpreter.cpp#L1916-L1958)

| Standard | Role |
| --- | --- |
| [BIP340](https://github.com/bitcoin/bips/blob/master/bip-0340.mediawiki) | Defines Schnorr signatures and x-only public keys on secp256k1. |
| [BIP341](https://github.com/bitcoin/bips/blob/master/bip-0341.mediawiki) | Defines the Taproot output, commitment, and key and script spending paths. |
| [BIP342](https://github.com/bitcoin/bips/blob/master/bip-0342.mediawiki) | Defines the Tapscript language used by the corresponding script-path leaf version. |

Syscoin uses Bech32m for Taproot addresses and applies the selected network’s address prefix. Query the network and deployment on your node before integrating wallet or transaction tooling. Add `-testnet` for Tanenbaum.
