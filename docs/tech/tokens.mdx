# Syscoin assets

SYS is the native currency on Syscoin’s UTXO and NEVM layers. Native UTXO outputs can also represent Syscoin Platform Tokens. Contracts on NEVM can implement standard EVM tokens. For any integration that links the two representations, verify the asset identifier, contract, bridge route, and confirmation policy.

Use supported [UTXO integration interfaces](/docs/dev-resources/sys/exchange-integration) for the current release. Syscoin Core 5.0 retired the 4.x asset-creation, update, balance, and allocation RPC family. [Core 5.0 release notes](https://github.com/syscoin/syscoin/blob/v5.0.0/doc/release-notes/release-notes-5.0.0.md#9-removal-of-deprecated-syscoin-4x-asset-rpcs)
