# Rollux

Rollux is an OP Stack network in the Syscoin ecosystem. Wallets connect to Rollux Mainnet with chain ID `570`. SYS on Rollux has its own balance, and the Rollux Portal moves funds between Rollux and Syscoin NEVM. [Rollux wallet and network settings](../guides/rollux/metamask.mdx) · [Rollux project](https://rollux.com/)

zkSYS has a separate public testnet, Genesis. Its Edgechains use Gateway for batch settlement. [zkSYS execution and settlement](../architecture/zksys.mdx)
