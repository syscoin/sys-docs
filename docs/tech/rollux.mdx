# Rollux

Rollux is a separate OP Stack network in the Syscoin ecosystem. It has its own chain ID, RPCs, bridges, and release schedule. Use its project documentation to verify the deployment and integration details for your target network. [Rollux project](https://rollux.com/)

For Syscoin’s public zkSYS test network and proof architecture, see [zkSYS execution and settlement](../architecture/zksys.mdx).
