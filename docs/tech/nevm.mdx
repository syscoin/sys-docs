# NEVM

NEVM is Syscoin’s Ethereum-compatible execution chain. Syscoin Core and sysgeth coordinate on the NEVM execution blocks linked to the UTXO ledger. Wallets and smart contract tooling use Ethereum JSON-RPC with the appropriate chain ID.
