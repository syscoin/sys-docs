# Sentry Nodes

Sentry Nodes register collateral on Core and participate in quorums that sign ChainLocks. Under the released rules, a quorum uses a BLS threshold signature to identify a block at a specific height. Core derives quorum membership from the eligible nodes on its deterministic list. [Sentry operator guide](../guides/sentrynode_setup.mdx) · [Node and quorum RPCs](../reference/core.mdx)

Post-quantum ChainLocks use SLH-DSA to authenticate operators and scheduled WOTS+ keys to sign block votes. Full nodes check the signatures in each certificate. [Post-quantum ChainLocks](../architecture/post-quantum.mdx)
