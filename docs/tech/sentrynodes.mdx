# Sentry Nodes

Sentry nodes are collateralized participants in Core’s deterministic node list. Under the released classical ChainLock design, the network derives quorums from eligible registered nodes and uses BLS threshold signatures. The PQ design changes the authentication and quorum signing model.

- [Sentry operator guide](/docs/guides/sentrynode_setup) covers the released network.
- [Post-quantum ChainLocks](/docs/architecture/post-quantum) covers the candidate.
- [Core command reference](/docs/reference/core) describes read-only checks for node and quorum state.
