## Cryptography and proofs

- FIPS 205 specifies SLH-DSA. The post-quantum Sentry identity scheme uses the SHAKE-128s profile. ChainLock votes use scheduled WOTS+ keys. [FIPS 205](https://csrc.nist.gov/pubs/fips/205/final) · [Post-quantum ChainLocks](../architecture/post-quantum.mdx)
- The zkSYS smart-account precompile uses the separate SLH-DSA-SHA2-128-24 profile. A signer must enforce the limit of 2²⁴ signatures per key. ERC-4337 describes the smart-account operation format. [NIST SP 800-230 draft](https://csrc.nist.gov/pubs/sp/800/230/ipd) · [Implementation and conformance notes](https://github.com/syscoin/zksync-os-server/blob/v0.24.4/contracts/README.md#slh-dsa-sha2-128-24-verifier-status) · [ERC-4337](https://eips.ethereum.org/EIPS/eip-4337)
- Core PoDA accepts BLAKE2s and legacy Ethereum Keccak-256. [BLAKE2s, RFC 7693](https://www.rfc-editor.org/rfc/rfc7693) · [PoDA digest encoding](../architecture/data-availability.mdx#what-the-hash-commits-to)
- Airbender uses DEEP-FRI to prove RISC-V execution. A wrapped proof also depends on the deployed wrapper. [FRI paper](https://doi.org/10.4230/LIPIcs.ICALP.2018.14) · [DEEP-FRI](https://arxiv.org/abs/1903.12243) · [zkSYS proving and wrapping](../architecture/zksys.mdx#why-there-are-two-proof-stages)

## Design essays by Jagdeep Sidhu

### How the design developed {#from-a-computational-court-to-authority-over-scarce-resources}

The 2021 design used the term *computational court* for a common settlement layer. Applications could execute independently while users relied on shared rules to settle claims. Later essays applied the same idea to published data, Bitcoin interoperability, and delegated authority. [Coordinated financial computing](https://jsidhu.medium.com/a-design-for-an-efficient-coordinated-financial-computing-platform-ab27e8a825a0)

### Earlier proposals for cross-chain data and Bitcoin collateral

The zkDA proposal explored a light client for verifying Syscoin data commitments on another chain. The Bitcoin Layer 0 essay explored difficulty-based stBTC. The current Bitcoin bridge research uses Bitcoin coinbase references as evidence for disputing a withdrawal. [zkDA proposal](https://syscoin.org/news/introducing-zkda) · [Bitcoin Layer 0 essay](https://jsidhu.medium.com/rollux-creating-a-new-layer-0-for-bitcoin-modularity-e2d737c99168) · [Bitcoin bridge research](../architecture/bitcoin-bridge.mdx)
