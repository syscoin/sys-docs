## Read a Syscoin block from a terminal

This example uses `curl` and `jq`. The first request identifies the indexer’s chain and sync state. The next two read a public mainnet block and its first transaction. Use `https://blockbook-dev.syscoin.org` for Tanenbaum UTXO reads with a testnet block height or transaction ID. [Mainnet indexer](https://blockbook.syscoin.org/api/v2) · [Testnet indexer](https://blockbook-dev.syscoin.org/api/v2)

```bash
book=https://blockbook.syscoin.org
curl -fsS "$book/api/v2" | jq '{coin: .blockbook.coin, chain: .backend.chain, inSync: .blockbook.inSync}'

txid=$(curl -fsS "$book/api/v2/block/2345720?pageSize=1" | jq -er '.txs[0].txid')
curl -fsS "$book/api/v2/tx/$txid" | jq '{txid, blockHeight, confirmations}'
```

The transaction belongs to block **2,345,720**. To read a public address, use `GET /api/v2/address/{address}?details=basic`. To get spendable candidates from confirmed transactions, use `GET /api/v2/utxo/{address}?confirmed=true`. UTXO values are integer strings in satoshis, with 100,000,000 satoshis per SYS. [Blockbook API](../dev-resources/documentation/javascript-sdk-ref/blockbook.mdx)

## Call your own Core node

With a running local daemon, `syscoin-cli` uses the node’s local RPC credentials. Run `syscoin-cli help` to list commands available in that build and `syscoin-cli help <command>` for parameters and result fields. The example reads the active chain and its tip. On Tanenbaum, add `-testnet` to each call. [Core ports and commands](./core.mdx)

```bash
syscoin-cli getblockchaininfo
tip=$(syscoin-cli getbestblockhash)
syscoin-cli getblockheader "$tip"
```
