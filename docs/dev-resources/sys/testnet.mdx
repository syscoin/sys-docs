# Syscoin test networks

For UTXO testing, install a released [Syscoin Core build](https://github.com/syscoin/syscoin/releases) and keep the testnet data separate from your mainnet data. Check the installed version’s options with `syscoind -help`.

```bash
syscoin-cli -testnet getblockchaininfo
syscoin-cli -testnet getnetworkinfo
```

Those examples assume a running Tanenbaum Core node. Read the `chain`, `blocks`, and `headers` fields to confirm the connection and sync state. For EVM development, use [NEVM Tanenbaum](/docs/reference/nevm) or [zkSYS Genesis](/docs/reference/zksys) and check the chain ID first. [Test funds](/docs/dev-resources/tsys)
