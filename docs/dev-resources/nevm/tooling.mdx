# NEVM development tools

NEVM exposes Ethereum JSON-RPC and works with EVM smart contract tooling. Run the [network checks](../../reference/nevm.mdx) first and test with an account reserved for testnet.

- [Foundry](./foundry.mdx) for Solidity builds, tests, and RPC inspection.
- [Hardhat](./hardhat.mdx) for TypeScript workflows.
- [NEVM wallet setup](../../guides/nevm/wallet-setup.mdx) for connecting a wallet.
