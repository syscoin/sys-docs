# NEVM development tools

NEVM exposes Ethereum JSON-RPC and works with EVM smart contract tooling. Run the [network checks](/docs/reference/nevm) first and test with an account reserved for testnet.

- [Foundry](./foundry.mdx) for Solidity builds, tests, and RPC inspection.
- [Hardhat](./hardhat.mdx) for TypeScript workflows.
- [NEVM wallet setup](/docs/guides/nevm/wallet-setup) for connecting a wallet.
