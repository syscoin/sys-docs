# Rollups on Syscoin

A rollup needs execution, a way to retrieve transaction data, and settlement rules that a verifier can check. An EVM-compatible RPC tells you how to connect. Its verifier and data path define the security properties for a particular deployment.

- [zkSYS](/docs/architecture/zksys) explains the Edgechain, Gateway, and settlement design.
- [Data availability](/docs/architecture/data-availability) explains payload publication and recovery.
- [Rollux](/docs/tech/rollux) links to the separate OP Stack project.
