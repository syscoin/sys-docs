# Rollups on Syscoin

In the zkSYS design, an Edgechain executes transactions and publishes its batch data on Syscoin Core. Gateway carries the ordered blob references and settles Edgechain batches under its configured proof and finality rules. Gateway’s own batches settle on NEVM. The blob data lets another operator recover the publication, while the deployed verifier determines which execution claims settlement enforces.
