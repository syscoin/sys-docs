---
title: Documentation and libraries
---

- Use the Solidity reference for language features, compiler settings, and the ABI. For NEVM, use the EVM target in our deployment guides. [Solidity documentation](https://docs.soliditylang.org/)
- **Viem** and **ethers** provide TypeScript and JavaScript clients for contracts and JSON-RPC. Configure the NEVM chain ID and endpoint when instantiating a client. [Viem documentation](https://viem.sh/docs/getting-started) · [ethers v6 documentation](https://docs.ethers.org/v6/)
- **OpenZeppelin Contracts** provides implementations of common token standards and access-control primitives. Choose a released library version compatible with your compiler and EVM target. [OpenZeppelin Contracts documentation](https://docs.openzeppelin.com/contracts/5.x/)

Use the [NEVM network reference](../../reference/nevm.mdx) to check your RPC connection. The [Foundry](./foundry.mdx) and [Hardhat](./hardhat.mdx) guides pin a Solidity version and EVM target for the sample contract.
