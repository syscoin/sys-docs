---
title: Deploy with Remix
---

[Remix](https://remix.ethereum.org/) can compile contracts and send deployments through a browser wallet. Connect the wallet to **Tanenbaum NEVM**, chain ID `5700`, then check the active network in both tools. [NEVM wallet setup](../../guides/nevm/wallet-setup.mdx)

1. Compile a test contract. The [Foundry example](./foundry.mdx) uses Solidity `0.8.28` and targets `paris`.
2. In Remix's Deploy & Run panel, select the browser extension environment.
3. Review the deployment request in the wallet and confirm on Tanenbaum.
4. Check the receipt and contract address using the [NEVM reference](../../reference/nevm.mdx).

Follow the current IDE documentation for wallet connections and deployment controls. [Remix Deploy & Run](https://remix-ide.readthedocs.io/en/latest/run.html)
