# UTXO developer interfaces

[Blockbook](/docs/dev-resources/documentation/javascript-sdk-ref/blockbook) exposes indexed UTXO transaction and address lookups. [Syscoinjs-lib](https://github.com/syscoin/syscoinjs-lib) provides application tooling. Use the SDK documentation for your installed version and check that it supports the Core and asset format you use.

See the [Core RPC reference](/docs/reference/core) for direct node access and [NEVM JSON-RPC](/docs/reference/nevm) for EVM development.
