# UTXO developer interfaces

[Blockbook](./blockbook.mdx) exposes indexed UTXO transaction and address lookups. [Syscoinjs-lib](https://github.com/syscoin/syscoinjs-lib) provides application tooling. Use the SDK documentation for your installed version and check that it supports the Core and asset format you use.

See the [Core RPC reference](../../../reference/core.mdx) for direct node access and [NEVM JSON-RPC](../../../reference/nevm.mdx) for EVM development.
