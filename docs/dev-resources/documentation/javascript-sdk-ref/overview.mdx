# UTXO developer interfaces

[SyscoinJS](./syscoinjs.mdx) gives a Node.js application the same transaction library Pali uses. Start with a public mainnet read, then build an unsigned testnet payment. Use [Blockbook](./blockbook.mdx) directly for indexed blocks, transactions, addresses and unspent outputs over REST or WebSocket.

A local Core node exposes UTXO consensus and wallet RPCs, including ChainLock and Z-DAG checks. NEVM contracts use Ethereum JSON-RPC. [Core commands](../../../reference/core.mdx) · [NEVM JSON-RPC](../../../reference/nevm.mdx)
