# Syscoinjs-lib

See the [Syscoinjs-lib source and versioned examples](https://github.com/syscoin/syscoinjs-lib). Pin the SDK for your application and use the examples from that release. The Core 4.x asset commands are historical and differ from the current UTXO asset model.

For indexed lookups use the [Blockbook API](./blockbook.mdx). For direct node access, see the [Core command reference](../../../reference/core.mdx).
