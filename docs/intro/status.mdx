Syscoin Core and NEVM run on mainnet and on the Tanenbaum testnet. zkSYS Genesis is a separate public testnet that settles through Gateway on Tanenbaum NEVM.

## Mainnet and testnets {#released-networks-and-public-records}

| Network | Available today | Connect or verify |
| --- | --- | --- |
| **Syscoin Core mainnet** | SYS and UTXO assets, Bitcoin merge mining, BLS ChainLocks, and Proof of Data Availability (PoDA). | [Core releases](https://github.com/syscoin/syscoin/releases) · [Core RPC](../reference/core.mdx) · [Mainnet Blockbook](https://blockbook.syscoin.org/) |
| **Syscoin NEVM mainnet** | Ethereum-compatible contracts on chain ID **57**. Ordinary accounts use secp256k1 signatures. | [NEVM RPC and wallet settings](../reference/nevm.mdx#endpoints-and-wallet-settings) · [Mainnet explorer](https://explorer.syscoin.org/) |
| **Tanenbaum testnet** | Core testnet and Tanenbaum NEVM on chain ID **5700**. | [Testnet Core setup](../dev-resources/sys/testnet.mdx) · [Tanenbaum explorer](https://explorer.tanenbaum.io/) |
| **zkSYS Genesis testnet** | zkSYS application execution on chain ID **57057**. Edgechain batches settle on Gateway. Gateway batches settle on Tanenbaum NEVM. | [Genesis quickstart](../reference/zksys.mdx#start-on-zksys-genesis) · [Genesis explorer](https://explorer-zk.tanenbaum.io/) |

In the [worked Genesis transaction](../reference/zksys.mdx#trace-a-public-testnet-transaction), Gateway batch **9,448** settled on Tanenbaum NEVM with a mock proof. Check the verifier and proof format for the specific batch you are inspecting.

## Development and research {#candidate-rules-design-targets-and-research}

| Work | Status |
| --- | --- |
| [Post-quantum ChainLocks](../architecture/post-quantum.mdx) | **Regtest.** Core verifies hash-based Sentry votes directly. Mainnet uses BLS ChainLocks, and the mainnet activation height for post-quantum ChainLocks is unset. |
| [NEVM data availability lookup](../reference/zksys.mdx#check-nevm-registration) | **Released.** Contracts query recent data registrations through the NEVM precompile at `0x63`. An index update in development improves handling of repeat registrations and reads during head changes. [NEVM index design](https://github.com/syscoin/go-ethereum/blob/1c046ba92f8ea95be024a790e9444b80ccbf019a/docs/syscoin-data-hash-index-upgrade.md) |
| [zkSYS validity proofs](../architecture/zksys.mdx#why-there-are-two-proof-stages) | **Deployment dependent.** The zkSYS stack supports real batch proofs. Check the settlement verifier, verification key, and proof type on the deployment you use. |
| [zkSYS issuance and gas credit](../architecture/zksys.mdx#sys-collateral-issuance-and-gas) | **Reference design.** Eligible SYS stake or Sentry collateral sets reward weight. The separate zkSYS token can fund eligible fees through the Gas Tank where the contracts are deployed and configured. |
| [Bitcoin withdrawals](../architecture/bitcoin-bridge.mdx#from-detection-to-enforcement-on-bitcoin) | **Research.** The proposed bridge uses a conflicting Syscoin history referenced in a Bitcoin coinbase to challenge a withdrawal. Witness encryption is a separate research direction. |
