---
title: What Syscoin provides
sidebar_position: 3
---

Syscoin gives applications a shared history secured by Bitcoin merge-mining and [post-quantum ChainLocks](../architecture/post-quantum.mdx). It gives applications two ways to use that history. Publish the bytes needed to reconstruct state through [PoDA](../architecture/data-availability.mdx), and use [NEVM](../reference/nevm.mdx) contracts to verify and settle state transitions.

[zkSYS](../architecture/zksys.mdx) is the scaling example. Edgechains execute transactions locally and can use a shared Gateway to settle proofs. Each operator's job is visible in the protocol. Sequencers order transactions, provers produce evidence about execution, and settlement contracts check that evidence. The design calls for decentralized sequencing and proof production, with SYS-linked issuance and a way to pay fees in zkSYS.

Developers can [connect to NEVM](../reference/nevm.mdx) with EVM tools or [try zkSYS Genesis](../reference/zksys.mdx). Operators can [inspect Core](../reference/core.mdx) and check [network and release status](./status.mdx) before choosing a binary or endpoint.
