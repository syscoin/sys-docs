Syscoin combines a Bitcoin-merge-mined UTXO chain, post-quantum finality, and an Ethereum-compatible settlement environment called NEVM. An execution layer can publish its batch data through Core and have its state transitions verified on NEVM. [zkSYS](../architecture/zksys.mdx) shows how the pieces work together.

| Component | Purpose |
| --- | --- |
| [Core](../architecture/core.mdx) | Validates UTXO transactions and accepts parent proof of work through AuxPoW. |
| [PQ ChainLocks](../architecture/post-quantum.mdx) | Add Sentry quorum finality using SLH-DSA identities and scheduled WOTS+ votes. |
| [PoDA](../architecture/data-availability.mdx) | Publishes payloads and binds their bytes to hash commitments that anyone can check after retrieval. |
| [NEVM](../reference/nevm.mdx) | Runs Ethereum-compatible contracts, including verification and settlement contracts. |
| [zkSYS](../architecture/zksys.mdx) | Executes on an Edgechain and sends commitments and proofs through Gateway. Its issuance uses SYS-linked reward eligibility, and its Gas Tank lets users spend zkSYS on eligible fees. |

The architecture describes the system with PQ active and zkSYS settling validity proofs. Check [network and release status](./status.mdx) for active configurations, and the [command reference](../reference/overview.mdx) for commands you can run now.
