---
title: Set up a Syscoin NEVM wallet
description: Add Syscoin NEVM Mainnet or Tanenbaum to Pali Wallet or MetaMask and fund a test account.
---

Use [Pali Wallet](https://paliwallet.com) or [MetaMask](https://metamask.io/download/) with an EVM account. In Pali, select the Syscoin NEVM network if it is already listed. In MetaMask or another EVM wallet, add the network manually using the values below. [MetaMask network setup](https://support.metamask.io/configure/networks/how-to-add-a-custom-network-rpc/)

## Manual settings for MetaMask or other wallets

Tanenbaum is the Syscoin NEVM test network. Check the chain ID in your wallet before you sign a transaction or copy a deposit address for use with an exchange or bridge.

| Setting | Syscoin NEVM Mainnet | Syscoin NEVM Testnet (Tanenbaum) |
| --- | --- | --- |
| RPC URL | `https://rpc.syscoin.org` | `https://rpc.tanenbaum.io` |
| Chain ID | `57` | `5700` |
| Currency symbol | `SYS` | `tSYS` |
| Block explorer | [explorer.syscoin.org](https://explorer.syscoin.org) | [explorer.tanenbaum.io](https://explorer.tanenbaum.io) |

For a direct chain-ID check, use the [NEVM RPC reference](/docs/reference/nevm). The separate [zkSYS Genesis testnet](/docs/reference/zksys) uses chain ID `57057`.

## Fund your account

For Tanenbaum, follow the [Syscoin faucet instructions](https://support.syscoin.org/t/how-to-get-a-syscoin-faucet/876) under **Syscoin NEVM Testnet** and provide the public `0x` address you want to fund. For mainnet, confirm that the funding source supports the **Syscoin NEVM** network. UTXO SYS and NEVM SYS use different address formats.

Use a dedicated test account for deployment practice. The [Foundry](/docs/dev-resources/nevm/foundry) and [Hardhat](/docs/dev-resources/nevm/hardhat) guides show how to load a test signer through an encrypted keystore.
