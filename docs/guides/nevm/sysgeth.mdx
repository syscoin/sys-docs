# Syscoin Geth

`sysgeth` is the EVM client paired with Syscoin Core. Install the Core release and its supported sysgeth artifact from the [release documentation](https://github.com/syscoin/syscoin/releases). When operating a separately managed sysgeth, verify the pairing against the release's instructions before joining a network.

```bash
syscoind --version
sysgeth version
syscoind -help
sysgeth --help
```

For a locally managed RPC, bind administrative interfaces to trusted local transports. Expose only the read or submission APIs your clients need, and keep the Core-to-NEVM transport private. Wallets can confirm the selected network with `eth_chainId`.
