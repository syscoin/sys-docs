# Run an NEVM node

`sysgeth` is the NEVM execution client. It executes EVM transactions and serves Ethereum JSON-RPC. Syscoin Core manages it by default. If you run it as a separate service, use the client version supported by your Core release. [Syscoin Core releases](https://github.com/syscoin/syscoin/releases)

```bash
syscoind --version
sysgeth version
syscoind -help
sysgeth --help
```

Keep the connection between Core and the NEVM client private. Expose only the JSON-RPC methods your applications need, and use `eth_chainId` to check which network the endpoint serves. [NEVM JSON-RPC](../../reference/nevm.mdx) · [NEVM client source](https://github.com/syscoin/go-ethereum)
