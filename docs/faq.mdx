Check [network status](./intro/status.mdx), then use the matching [NEVM](./reference/nevm.mdx), [zkSYS](./reference/zksys.mdx), or [Core](./reference/core.mdx) reference. Ethereum-compatible wallets identify networks by chain ID.

## What is the difference between PoDA and storing data forever?

A hash lets a reader authenticate bytes they can retrieve. Core requires payloads when validating fresh publications. A node syncing historical blocks can accept older commitments after the payload requirement expires. An application that needs to replay those batches later must obtain the bytes from a source that kept them. [Publication, retention, and replay](./architecture/data-availability.mdx#retention-and-replay)
